# macOS 本地服务网关搭建指南

## 为什么需要

本地开发时通常有多个服务跑在不同端口（3000、8080、1010...），端口多了很难记。通过搭建本地反向代理 + DNS，可以用域名代替端口访问，例如：

- `stock.d.me` 代替 `localhost:1010`
- `newapi.d.me` 代替 `localhost:1001`

## 整体架构

```
浏览器 → stock.d.me
              ↓ (DNS: *.d.me → 127.0.0.1)
         127.0.0.1:80 (Nginx Proxy Manager)
              ↓ (反向代理)
         host.docker.internal:1010 (实际服务)
```

三个组件各司其职：

| 组件 | 作用 | 部署方式 |
|------|------|---------|
| Nginx Proxy Manager | 反向代理，管理路由规则 | Docker |
| dnsmasq | 本地 DNS，`*.d.me` 通配解析到 127.0.0.1 | brew |
| macOS resolver | 告诉系统 `*.d.me` 走本地 dnsmasq | `/etc/resolver/` |

## 第一步：安装 dnsmasq

```bash
brew install dnsmasq
```

## 第二步：配置 dnsmasq

创建域名解析规则：

```bash
echo "address=/d.me/127.0.0.1" > /opt/homebrew/etc/dnsmasq.d/d.me.conf
```

编辑 dnsmasq 主配置 `/opt/homebrew/etc/dnsmasq.conf`，取消注释并修改以下三项：

```
listen-address=10.0.0.1
bind-interfaces
conf-dir=/opt/homebrew/etc/dnsmasq.d/,*.conf
```

> **为什么要绑定 10.0.0.1 而不是 127.0.0.1？**
>
> macOS 的 `/etc/resolver/` 机制要求 dnsmasq 运行在非 localhost 的 53 端口上才能稳定工作。所以需要给本机创建一个虚拟 IP `10.0.0.1`。

## 第三步：创建 loopback alias

给本机添加虚拟 IP `10.0.0.1`：

```bash
# 立即生效
sudo ifconfig lo0 alias 10.0.0.1
```

开机自动创建（持久化）：

```bash
sudo bash -c 'cat > /Library/LaunchDaemons/com.local.loopback-alias.plist << EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.local.loopback-alias</string>
    <key>ProgramArguments</key>
    <array>
        <string>ifconfig</string>
        <string>lo0</string>
        <string>alias</string>
        <string>10.0.0.1</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
</dict>
</plist>
EOF'

sudo launchctl load /Library/LaunchDaemons/com.local.loopback-alias.plist
```

## 第四步：配置 macOS resolver

告诉 macOS：`*.d.me` 的 DNS 查询走 `10.0.0.1`（即 dnsmasq）：

```bash
sudo mkdir -p /etc/resolver
sudo bash -c 'printf "nameserver 10.0.0.1\n" > /etc/resolver/d.me'
```

## 第五步：启动 dnsmasq

```bash
sudo brew services start dnsmasq
```

验证 DNS 解析：

```bash
dscacheutil -q host -a name stock.d.me
# 应输出: name: stock.d.me  ip_address: 127.0.0.1
```

> **注意**：`dig stock.d.me` 不会走 macOS resolver，验证要用 `dscacheutil`。

## 第六步：部署 Nginx Proxy Manager

创建 `docker-compose.yml`：

```yaml
services:
  app:
    image: jc21/nginx-proxy-manager:latest
    restart: unless-stopped
    ports:
      - "80:80"
      - "81:81"
      - "443:443"
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

启动：

```bash
docker compose up -d
```

访问 `http://localhost:81` 进入管理界面，首次登录：

- 邮箱：`admin@example.com`
- 密码：`changeme`
- **登录后立即修改密码**

## 第七步：添加服务

### 通过 Web UI

1. 打开 `http://localhost:81`
2. Proxy Hosts → Add Proxy Host
3. 填写：
   - Domain Names: `stock.d.me`
   - Scheme: `http`
   - Forward Hostname/IP: `host.docker.internal`
   - Forward Port: `1010`
4. Save

### 通过 API

```bash
# 登录
TOKEN=$(curl -s -X POST http://localhost:81/api/tokens \
  -H "Content-Type: application/json" \
  -d '{"identity":"your@email.com","secret":"your-password"}' \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['token'])")

# 添加代理
curl -s -X POST "http://localhost:81/api/nginx/proxy-hosts" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "domain_names": ["stock.d.me"],
    "forward_scheme": "http",
    "forward_host": "host.docker.internal",
    "forward_port": 1010,
    "certificate_id": 0,
    "ssl_forced": false,
    "hsts_enabled": false,
    "hsts_subdomains": false,
    "trust_forwarded_proto": false,
    "http2_support": false,
    "block_exploits": false
  }'
```

## 常见问题

### 浏览器打不开 `stock.d.me`

清 DNS 缓存或用无痕模式。macOS DNS 缓存刷新：

```bash
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
```

### Docker 容器内访问本机服务

用 `host.docker.internal` 而不是 `localhost`，因为 `localhost` 在容器内指向容器自己。

### 新加的服务域名不生效

`*.d.me` 是通配解析，新服务自动生效，不需要改 DNS 配置。

### 重启电脑后服务还在吗？

- dnsmasq：`brew services` 注册的 launchd 服务，自动启动
- NPM：Docker 的 `restart: unless-stopped` 策略，Docker Desktop 自启动则自动恢复
- `10.0.0.1` alias：通过 LaunchDaemon 持久化，自动创建

| 文件 | 作用 |
|------|------|
| `/opt/homebrew/etc/dnsmasq.d/d.me.conf` | dnsmasq 域名解析规则 |
