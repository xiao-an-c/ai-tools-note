# 本地命令工具

本机安装的命令行工具，用于简化本地开发环境操作。

## local-tb — 本地开发工具箱

### 安装

```bash
cd /Users/denglian/claude-workspace/local-tool-box
npm install -g .
```

安装时会自动检测并提示安装依赖（mitmproxy、wireguard-go）。

### 初始化

首次使用前执行：

```bash
# 初始化 shell 配置
local-tb init

# 使配置生效
source ~/.zshrc
```

### 代理模式对比

| 模式 | 作用范围 | 命令 | 权限 | 需要依赖 |
|------|---------|------|------|---------|
| **终端代理** | 当前终端 CLI 工具 | `local-tb proxy on` | 无 | mitmproxy |
| **全局开关** | 所有新终端 CLI 工具 | `local-tb proxy global-on` | 无 | mitmproxy |
| **系统代理** | 尊重系统代理的应用（浏览器） | `local-tb proxy system-on` | 无 | mitmproxy |
| **TUN 模式** | 系统级所有流量 | `sudo local-tb proxy tun-start` | sudo | mitmproxy + wireguard-go |

### 命令

#### `local-tb proxy` — 代理抓包管理

基于 mitmproxy 的 HTTP(S) 代理抓包工具。

**启动/停止 mitmproxy**

```bash
# 启动 Web 模式（默认端口 8080）
local-tb proxy start

# 指定端口
local-tb proxy start -p 8888

# 启动 dump 模式（纯命令行输出）
local-tb proxy start -m dump

# 停止
local-tb proxy stop
```

| 模式 | 说明 | UI |
|------|------|-----|
| web | Web 控制台（默认） | http://127.0.0.1:8081 |
| dump | 纯日志输出 | 终端 |
| tui | 终端交互界面 | 终端 |

**查看状态**

```bash
local-tb proxy status
```

显示所有代理状态：
- mitmproxy 进程状态
- 当前终端代理状态
- 全局开关状态
- 系统代理状态
- TUN 模式状态

**终端代理（环境变量）**

```bash
# 当前终端启用
eval "$(local-tb proxy on)"

# 当前终端关闭
eval "$(local-tb proxy off)"
```

**全局开关（影响新终端）**

```bash
# 全局开启 - 新开终端自动启用代理
local-tb proxy global-on

# 全局关闭
local-tb proxy global-off
```

**系统代理（浏览器等应用）**

```bash
# 开启系统代理 - 浏览器直接可用
local-tb proxy system-on

# 关闭系统代理
local-tb proxy system-off
```

> **注意**：系统代理会影响所有尊重系统代理设置的应用（浏览器、部分 GUI 应用等）

**TUN 模式（系统级流量拦截）**

```bash
# 启动 TUN 模式（需要 sudo 和 wireguard-go）
sudo local-tb proxy tun-start

# 停止 TUN 模式
local-tb proxy tun-stop
```

> **注意**：TUN 模式在 IP 层拦截所有流量，需要 root 权限创建虚拟网卡

### 使用场景

#### 场景 1：调试终端请求

```bash
# 启动代理
local-tb proxy start
eval "$(local-tb proxy on)"

# 运行你的代码
curl https://api.github.com/users/octocat

# 在 http://127.0.0.1:8081 查看
```

#### 场景 2：浏览器抓包

```bash
# 启动代理和系统代理
local-tb proxy start
local-tb proxy system-on

# 浏览器直接访问网站，所有流量被拦截
# 访问 http://127.0.0.1:8081 查看
```

#### 场景 3：全局流量拦截

```bash
# 启动 TUN 模式（需要先安装 wireguard-go）
sudo local-tb proxy tun-start

# 所有应用的流量都会被代理
```

### 依赖

安装时会自动检测并提示安装：

```bash
# 必需
brew install mitmproxy

# 可选（TUN 模式需要）
brew install wireguard-go
```

### 常见问题

**Q: 浏览器访问 mitm.it 显示错误？**

A: 需要先开启系统代理：
```bash
local-tb proxy system-on
```

**Q: TUN 模式启动失败？**

A: 检查是否安装了 wireguard-go：
```bash
brew install wireguard-go
```

**Q: 如何查看当前代理状态？**

A: 使用 status 命令：
```bash
local-tb proxy status
```
