# 本地服务路由表

当前已配置的所有本地服务路由，通过 Nginx Proxy Manager 管理。

## 服务列表

| 域名 | 转发目标 | 说明 |
|------|---------|------|
| [note.d.me](http://note.d.me) | NPM 直接托管 dist 静态文件 | 知识笔记 VitePress（private 构建） |
| [stock.d.me](http://stock.d.me) | host.docker.internal:1010 | 股票财务数据分析系统（API 文档：[/api/docs](http://stock.d.me/api/docs)） |
| [newapi.d.me](http://newapi.d.me) | host.docker.internal:1001 | NewAPI |

## 管理入口

- **NPM 管理界面**：`http://localhost:81`
- **NPM API**：`http://localhost:81/api`

## 域名规则

所有服务使用 `*.d.me` 域名，由 dnsmasq 通配解析到 `127.0.0.1`，添加新服务时域名自动生效。

## 注意

- 服务统一使用 `http://`，未配置 SSL
- 浏览器首次访问可能需要清 DNS 缓存或使用无痕模式
