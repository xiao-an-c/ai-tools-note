# 使用 mitmproxy 调试本地网络请求

## 为什么需要

开发调试时经常需要查看请求和响应的完整内容：接口返回了什么、请求头带没带 Cookie、有没有重定向……浏览器 DevTools 只能看浏览器的请求，如果需要抓取命令行工具、其他应用、甚至手机的请求，就需要一个代理抓包工具。

[mitmproxy](https://mitmproxy.org/) 是一个免费开源的交互式 HTTPS 代理，支持终端 UI、Web UI 和命令行三种模式。

## 安装

```bash
brew install mitmproxy
```

安装后提供三个命令：

| 命令 | 界面 | 适用场景 |
|------|------|---------|
| `mitmproxy` | 终端交互 UI | 快速查看、过滤、重放请求 |
| `mitmweb` | 浏览器 Web UI | 最直观，推荐日常使用 |
| `mitmdump` | 纯命令行输出 | 脚本化处理、日志记录 |

## 快速上手

### 启动 Web UI

```bash
mitmweb
```

启动后会：
1. 在 `127.0.0.1:8080` 启动代理服务
2. 自动打开浏览器访问 `http://127.0.0.1:8081`，显示 Web UI

### 配置系统代理

要让应用走 mitmproxy，需要把系统或应用的代理设为 `127.0.0.1:8080`。

**方式一：macOS 系统代理（影响所有应用）**

```bash
# 开启
export https_proxy=http://127.0.0.1:8080
export http_proxy=http://127.0.0.1:8080
```

**方式二：仅对单个命令生效**

```bash
https_proxy=http://127.0.0.1:8080 curl -v https://httpbin.org/get
```

**方式三：浏览器使用 SwitchyOmega 等插件**

安装浏览器代理插件，设置为 `127.0.0.1:8080`，可以随时切换是否走代理。

### 抓取 HTTPS 请求

HTTPS 流量默认会显示为 TLS 握手失败，需要安装 mitmproxy 的 CA 证书：

1. 启动 `mitmweb`
2. 浏览器访问 `http://mitm.it`
3. 下载对应平台的证书并安装
4. macOS 上安装后需要到 **系统设置 → 隐私与安全性 → 证书管理** 中，将 `mitmproxy` 证书的信任状态改为"始终信任"

> **为什么需要这一步？** mitmproxy 作为中间人代理，用自己的 CA 证书签发每个域名的证书。只有安装并信任了这个 CA，浏览器和系统才会接受它签发的证书。

## 结合本地网关使用

结合已有的 Nginx Proxy Manager + dnsmasq 环境，有两种使用方式：

### 方式一：抓取特定域名

在终端设置代理后，只抓取走代理的请求：

```bash
export https_proxy=http://127.0.0.1:8080
export http_proxy=http://127.0.0.1:8080
# 然后访问 stock.d.me 等本地服务
curl http://stock.d.me/api/xxx
```

### 方式二：拦截所有经过 NPM 的请求

如果想看所有经过 Nginx Proxy Manager 的请求而不装额外工具，可以直接查看 NPM 的访问日志：

```bash
tail -f local-router/data/logs/proxy-host-*_access.log
```

> **局限**：日志方式只能看到基本信息（状态码、路径、耗时），看不到请求体和响应体。需要完整内容时还是用 mitmproxy。

## 常用操作

### Web UI（mitmweb）

| 操作 | 说明 |
|------|------|
| 点击请求 | 查看完整的请求头、请求体、响应头、响应体 |
| 搜索栏 | 按域名、路径、内容过滤 |
| `~u` 过滤 | 按域名过滤，如 `~u stock.d.me` 只看股票服务 |
| `~m POST` 过滤 | 只看 POST 请求 |
| 右键 → Save | 保存请求/响应到文件 |

### 终端 UI（mitmproxy）

| 快捷键 | 说明 |
|--------|------|
| `?` | 帮助 |
| `f` | 设置过滤表达式 |
| `Enter` | 查看请求详情 |
| `Tab` | 在请求/响应之间切换 |
| `e` | 编辑并重放请求 |
| `q` | 返回上级 |

### 常用过滤表达式

```
# 按域名
~u stock.d.me

# 按方法
~m POST
~m GET

# 按状态码
~c 200
~c 4xx

# 组合
~u api & ~m POST & ~c 500
```

## 常见问题

### 终端 UI 乱码

mitmproxy 终端 UI 需要较新的终端支持。如果显示异常，改用 `mitmweb` 的 Web UI。

### 某些 App 不走系统代理

部分 App 会忽略系统代理设置。这种情况下可以考虑：
- 用 Proxyman（macOS 原生工具，支持自动配置）
- 配置 iptables/pf 转发流量到 mitmproxy

### 启动报端口被占用

```bash
# 指定其他端口启动
mitmweb --listen-port 8081
```
