# 中文设置

GSD 本身没有内置的中文语言包，但可以通过配置让 GSD 使用中文与你交流。

## 方法一：创建 CLAUDE.md

在项目根目录创建 `CLAUDE.md` 文件：

```markdown
# CLAUDE.md

## 语言设置

- **主要语言**：中文（Simplified Chinese）
- 所有输出、注释、文档使用中文
- 技术术语可在中文后附上英文原词
```

这样每次 Claude Code 启动时都会加载这个设置。

---

## 方法二：在 PROJECT.md 中指定

在 `/gsd:new-project` 时创建的 `.planning/PROJECT.md` 中添加语言设置：

```markdown
# Project: 我的项目

## 项目信息

- 语言：中文
- 时区：Asia/Shanghai

## 团队约定

- 所有沟通使用中文
- 代码注释使用中文
- 文档使用中文
```

---

## 方法三：直接告诉 GSD

在新会话开始时，直接告诉 Claude：

```
请用中文与我交流，所有输出使用中文。
```

---

## 说明

**GSD 的命令和界面本身都是英文的**，没有内置的中文语言包。

GSD 源码仓库中的 `docs/zh-CN/` 只是 GSD **项目自己的说明文档**（即介绍 GSD 是什么的文档），不是 GSD 运行时命令的中文翻译。

所以：
- `/gsd:new-project` 命令始终是英文
- GSD 生成的计划文件（如 `PLAN.md`）语言取决于你的设置
- 你可以让 Claude **用中文回答**，但 GSD 命令本身无法中文化

| 项目 | 语言 |
|------|------|
| GSD 命令 | 英文（如 `/gsd:new-project`） |
| GSD 交互语言 | 可配置为中文 |
| GSD 文档 | 有中文版 |
| 代码注释 | 取决于你的设置 |

---

## 推荐做法

**最佳实践**：在项目根目录创建 `CLAUDE.md`：

```bash
touch CLAUDE.md
```

内容：

```markdown
# CLAUDE.md

## 语言

- 所有交流使用中文
- 技术术语可附英文原文
- 注释使用中文

## 项目背景

（根据需要填写）
```

这样每次新会话、每次子代理启动，都会自动使用这个语言设置。
